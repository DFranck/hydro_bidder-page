# Project Onboarding Guide

This guide provides the necessary onboarding steps for projects interested in participating in Hydro. Hydro allocates liquidity through sequential monthly auction rounds, where projects compete by offering tributes to voters. Each round lasts one month. To maintain liquidity over a longer period, projects need to participate in subsequent rounds.
